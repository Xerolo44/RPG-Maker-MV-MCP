# v0.4 Track A — Foundation and Analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the unit-test harness, shared command-list utilities, tool profiles, editor awareness, transactional changesets with undo, `audit_assets` and `lint_events`.

**Architecture:** Pure logic lives in new `src/*.ts` modules and is tested with `node:test` against compiled `dist/`. `Project` (src/project.ts) gains write-staging for changesets and write-signature tracking for editor awareness. Tools are registered in new `src/tools/changesetTools.ts` and `src/tools/analysisTools.ts` plus one addition to `src/tools/maintenanceTools.ts`.

**Tech Stack:** TypeScript, zod, `node:test`, `@modelcontextprotocol/sdk` client (profiles test only).

**Spec:** `docs/superpowers/plans/2026-10-24-v0.4-00-overview.md` (scope, global constraints, deferred items).

## Global Constraints

- Node `>=18` on ubuntu + windows; `node --test` must be invoked with explicit file paths (no globs, no directory argument).
- ESM, `strict`, `NodeNext`, relative imports end in `.js`.
- Tool shape: `server.registerTool(name, {title, description, inputSchema}, safe(async …))`.
- All JSON writes via `Project.writeJson`; map/database arrays 1-indexed with `null` at 0.
- Branch `feat/v0.4-a-foundation`; never commit to `main`.

## Review Focus

1. Tools called before `set_project` return the standard error text (`No project selected`) — tested in A4–A7.
2. `lint_events` / `audit_assets` on a map with `events: [null]`, an event with `pages: []`, or a page whose `list` is missing: no crash, no findings for the hole.
3. `commit_changeset` with no active changeset, `begin_changeset` twice, `undo_changeset` with an empty journal: clear error messages, no state change.
4. `audit_assets` on a project with no `img/` or `audio/` folder: reports everything referenced as missing instead of throwing.
5. Changeset commit where one staged file contains invalid JSON text: nothing is written, original files untouched.
